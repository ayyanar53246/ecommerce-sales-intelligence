# E-Commerce Sales Intelligence Dashboard

## Project Overview
This project analyzes e-commerce sales data to help businesses make better decisions. It provides insights into revenue, profit, product performance, inventory levels, and product returns.

## Problem Statement
E-commerce companies need to identify their best-selling products, low-stock items, low-performing products, and product return rates. This dashboard helps analyze these problems using data.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Streamlit
- SQL and SQLite

## Key Features
1. Sales and revenue analysis
2. Product performance comparison
3. Inventory reorder alerts
4. Product return analysis
5. Interactive date and category filters
6. SQL database integration

## Real-World Business Benefits
- Helps identify high-performing products.
- Supports inventory management.
- Helps businesses monitor profits and returns.
- Supports data-driven business decisions.

## How to Run
1. Generate the dataset using `python generate_data.py`.
2. Start the dashboard using `python -m streamlit run app.py`.
3. Open the local URL displayed in the terminal.
